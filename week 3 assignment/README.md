 Overview

This project is developed as part of **Week 3 EF Core 8.0 Hands-On Labs**, demonstrating an end-to-end implementation of a **Retail Inventory System** using:
- Entity Framework Core (Code-First)
- SQL Server LocalDB
- Console Application in C#

The system allows you to **insert**, **retrieve**, **update**, **delete**, and **query** product records in a database using EF Core and LINQ.
| Lab # | Title |
|-------|-----------------------------------------------------------|
| 1     | Understanding ORM with a Retail Inventory System         |
| 2     | Setting Up the Database Context for a Retail Store       |
| 3     | Using EF Core CLI to Create and Apply Migrations         |
| 4     | Inserting Initial Data into the Database                 |
| 5     | Retrieving Data from the Database                        |
| 6     | Updating and Deleting Records                            |
| 7     | Writing Queries with LINQ                                |
